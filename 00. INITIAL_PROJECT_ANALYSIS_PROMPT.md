# 5. PDF417 — CRITICAL REQUIREMENT

PDF417 is a particularly important format for this project.

The architecture must provide a dedicated PDF417 validation path.

The project must evaluate:

* PDF417 detection
* PDF417 decoding
* Raw payload extraction
* Payload integrity
* Character encoding
* Structured-data detection
* Parser architecture
* Validation
* Unknown PDF417 payloads
* Invalid payloads
* Damaged PDF417
* Low-resolution PDF417
* Small PDF417
* Glare/reflection
* Blur
* Rotation
* Perspective distortion

## Critical Rule

**PDF417 does NOT automatically mean Bangladesh National ID data.**

A decoded PDF417 payload must first be treated as generic untrusted barcode data.

Only after verified evidence establishes that a payload conforms to a known NID-related structure may NID-specific processing be considered.

